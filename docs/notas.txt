##Compilado general del main.cpp 
    => Como añadir archivos de otra carpeta
        #include "../carpeta/archivo.hpp"
        #include "../carpeta/archivo.cpp"


    => Modo de compilado con "msys64 g++"
        g++ -Iinclude src/*.cpp -o math

        ¿Qué hace?
            g++             //Compila para C++
            -Iinclude       //Busca headders en la carpeta "include" con la clave "-I"
            src/*.cpp       //Compila todos los archivos .cpp dentro de la carpeta "src"
            -o math         //Al archivo .exe compilado, lo nombrará como "math"
